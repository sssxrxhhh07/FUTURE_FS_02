📊 MiniCRM Dashboard

A modern, responsive Customer Relationship Management (CRM) dashboard built using HTML, CSS, and JavaScript. MiniCRM helps users manage leads, track sales opportunities, visualize pipeline performance, and monitor business growth through an intuitive analytics dashboard.

🚀 Overview

MiniCRM is a lightweight CRM solution designed to simplify lead management and sales tracking. The application provides a clean user interface with real-time updates, analytics visualizations, lead categorization, and customizable settings.

The project focuses on creating a professional business dashboard experience while demonstrating frontend development, UI/UX design, and JavaScript functionality.
